# Desktop Countdown Widget

A lightweight countdown window built with Windows' built-in PowerShell + WPF. Just double-click to run — **no software installation needed**.

## How to use

1. Double-click `启动倒计时.bat` (the launcher; the filename means "start countdown") to open the countdown window.
2. The window stays **always on top** by default and appears at the top-right of the screen.

## Features

- ➕ Add / delete countdowns
- 📌 Toggle always-on-top, minimize, close
- 🖱️ Resize by dragging any edge or corner
- 🎨 5 color themes: Midnight Blue / Emerald Green / Violet / Warm Orange / Sakura Pink
- 🔊 Sound alert when a countdown ends (toggle in **Settings**)
- 🗂️ Multiple groups (enter a group name when adding; leave blank for "Default")
- ⬆️⬇️ Reorder cards with the up/down buttons

## Auto-start (optional)

To launch the widget automatically when Windows starts, double-click `设置开机自启.bat` (the filename means "set auto-start").

## Notes

- Your countdown data is saved locally in `countdown-data.txt` — it is **not** uploaded here.
- Runs fully offline; no internet connection required.
