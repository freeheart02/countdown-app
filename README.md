# 桌面倒计时小程序

一个用 Windows 自带的 PowerShell + WPF 写的小巧倒计时窗口，双击就能用，**无需安装任何软件**。

## 使用方法

1. 双击 `启动倒计时.bat`，即可打开倒计时窗口。
2. 窗口默认**置顶**显示在屏幕右上角，随时能看到。

## 功能

- ➕ 添加 / 删除倒计时
- 📌 置顶开关、最小化、关闭
- 🖱️ 拖动窗口四边四角可调整大小
- 🎨 5 种皮肤：深夜蓝 / 翡翠绿 / 紫罗兰 / 暖阳橙 / 樱花粉
- 🔊 倒计时结束时响铃（可在「设置」里开关）
- 🗂️ 多个分组（添加时填「分组」，留空归入「默认」）
- ⬆️⬇️ 每张卡片可上移 / 下移排序

## 开机自启（可选）

想让倒计时随电脑开机自动启动，双击 `设置开机自启.bat` 即可。

## 说明

- 你的倒计时数据保存在本机 `countdown-data.txt` 文件里，不会上传到这里。
- 纯本地运行，不需要联网。
